## 2. Unit suites

`node --test tests/*.test.mjs` → **146 tests, 146 pass, 0 fail** (database suites against local PostgreSQL 16, see above).

Two existing tests encoded behaviour this slice deliberately changes and were rewritten rather than patched:

- `commands`: "assignment rejects overlapping jobs for the cleaner" → *"rejects an overlapping chosen start and otherwise shifts to the first free one"*. An explicitly chosen start that overlaps is still refused (`Conflicts with another of your jobs that day`); with no start given the command now takes the first free 15-minute start in the window (10:00 → 11:30 behind a 10:30–11:30 job), which is the rule the marketplace UI shows.
- `quality-review`: the settlement report no longer refuses a `PROPERTY_MANAGER`. The test now asserts the approved shape: an unlinked manager sees zero jobs, a manager linked to the property sees `dueCents`/`chargedCents`, and `earnedCents`, `waitingReviewCents`, `payableCents` and `paidCents` are absent from both the summary and the job rows. `OPERATIONS_MANAGER` is still `Forbidden`.

The suites that exercise the new rules in plain JavaScript also pass: `domain` (marketplace window feasibility: window can no longer fit, job stays open after the window start, skips a conflict to the next free start, an explicit day off blocks taking), `frontend-security-contract` (hidden-field lists), `dispatch-contract`, `i18n-contract`, `migrations-order`.

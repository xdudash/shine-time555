# Практическая проверка: финансы и основные сценарии

Чек-лист для проверки вручную на тестовом аккаунте. Пункты с пометкой «авто» уже покрыты тестами в репозитории; остальные нужно пройти руками.

## 1. Сверка за месяц (Финансы → Сверка)

- [ ] Открывается страница, KPI «Клиенты / Клинеры» показывают итог и остаток к оплате. (авто: `finance-scale-browser`)
- [ ] Переключатель «По объектам / По клиентам / По клинерам» работает клавиатурой (Tab, Enter).
- [ ] Поиск по имени сужает список; «Выбрать всё» выбирает только найденных; «Снять выделение» очищает. (авто)
- [ ] Раскрытие строки показывает уборки контрагента с суммами и статусом. (авто)
- [ ] «Оплатить всё» у клиента: окно подтверждения показывает число уборок и сумму; после подтверждения остаток становится 0. (авто)
- [ ] «Оплатить выбранные» при сбое на втором пакете показывает «Записано N / M» с числом уже записанных уборок. (авто)
- [ ] Оплата по объекту («Отметить оплаченным» / «Отметить клинеров выплаченными») требует подтверждения. (авто)
- [ ] Ручная кнопка «Записать платёж» у каждой уборки отсутствует. (авто)
- [ ] Поправка даты и суммы у неоплаченной уборки сохраняется с причиной; у оплаченной поля заблокированы.

## 2. Роли и доступ

- [ ] Админ (владелец бизнеса) видит и подтверждает оплаты клиентов и клинеров.
- [ ] Управляющий операциями видит сверку и подтверждает оплаты по всем объектам.
- [ ] Управляющий имуществом видит и подтверждает оплаты только по своим объектам.
- [ ] Владелец-клиент не видит сверку и не может подтвердить свою оплату (отказ 403).
- [ ] Клинер не видит финансы сверки.

## 3. Выписки и печать

- [ ] Выписка клиента и клинера открывается из списка, CSV и печать/PDF дают те же суммы, что и на экране.
- [ ] Выписка содержит только завершённые уборки, принятые после проверки качества.

## 4. Остальные сценарии (проверка руками)

- [ ] Создание уборки админом, назначение клинера, принятие и выполнение клинером (мобильная ширина).
- [ ] Проверка качества: одобрение и возврат на доработку.
- [ ] Уведомления и переключение языков RU / SK / UK / EN.
- [ ] Отмена уборки и повторное открытие.

## 5. Нагрузка

Проверено на локальной базе PostgreSQL с 1 200 уборками за месяц (40 объектов, 30 клиентов, 28 клинеров):

| Операция | Время |
|---|---|
| Сверка за месяц (все уборки) | ≈ 250 мс |
| Список по клиентам / клинерам | ≈ 150 мс |
| Оплата 30 клиентов по их долгу (1 080 уборок, по пакету на клиента) | ≈ 0,4 с |
| Рендер страницы сверки в браузере (1 200 уборок) | ≈ 15 мс |
| Поиск по клиентам (1 200 уборок) | ≈ 30 мс |

Это измерения на тестовых данных, не на production. Перед запуском на реальных данных повторить замер на копии production-базы.
